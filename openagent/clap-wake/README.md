# Вызов ассистента двойным хлопком

Включается в Настройки → «Вызов двойным хлопком» (в шторке появляется значок «Жду двойной хлопок»). Хлопните дважды — откроется голосовой звонок.
Всё работает на телефоне, звук никуда не отправляется. На время голосового звонка прослушивание ставится на паузу.

**Как не просыпаться от аплодисментов** (два уровня):
1. `ClapDetector` (всегда, дёшево): ищет резкие короткие удары по громкости. Срабатывает только на **ровно два** удара с паузой 0,17–0,65 с,
   когда за 0,9 с до первого и 0,75 с после второго тишина. Серия хлопков (аплодисменты, ритм) этого условия не проходит.
2. **YAMNet** (TFLite, `assets/yamnet.tflite`, Apache-2.0): проверяет окно звука вокруг пары. Нужно: Clapping+Hands+Slap+Finger snapping ≥ порога,
   Applause < 0,35, Speech < 0,5. Стук, щелчок мыши, клавиатура, речь отсеиваются.

Чувствительность (Строго / Обычно / Чутко) меняет порог: 0,40 / 0,20 / 0,10. В настройках под переключателем видно, что услышал последний кандидат.

- `detector.py` — эталон детектора на Python, `calibrate.py` — калибровка на ESC-50.
- Ограничения Android: микрофонный фоновый сервис запускается только когда вы открыли приложение (после перезагрузки телефона откройте приложение один раз);
  открытие окна из фона требует разрешения «поверх других окон» или полноэкранных уведомлений, иначе придёт уведомление, на которое нужно нажать.
