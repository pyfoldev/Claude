# Словарь терминов

| Термин | Что значит |
|---|---|
| **Хендлер** | функция, обрабатывающая сообщение/кнопку (`handlers/*.py`) |
| **Роутер (router)** | группа хендлеров одного модуля; порядок подключения = приоритет |
| **Middleware** | прослойка, выполняемая до хендлеров |
| **`dp[...]`** | общие объекты, доступные хендлерам параметрами |
| **ДК** | «доступ команд» — минимальный ранг для каждой команды чата |
| **Ранг** | уровень модератора 0–5 |
| **Тоггл / группа команд** | включатель набора команд в чате (`toggles.GROUPS`) |
| **Страж заявок** | режим, когда бот принимает заявки на вступление и показывает капчу |
| **ДК, варн, мут, кик, бан** | стандартные меры модерации (`mod_service.py`) |
| **Нори** | имя бота в обращении («нори, баланс») |
| **РП** | ролевые действия («обнять @ник») — `rp_data.py` |
| **Rich-экран** | сообщение-карточка с таблицей и кнопками (`rich_ui.py`) |
| **Runtime (`rt`)** | глобальное состояние: блок-лист, флаги, обслуживание |
| **Premium** | подписка за звёзды Telegram (`handlers/premium.py`) |
| **Mini App / WebApp** | веб-страница внутри Telegram (капча, панель, конкурсы) |
| **Watchdog** | фоновый цикл, который периодически что-то досчитывает (дуэли, капча, пары) |
| **supervise** | обёртка, перезапускающая упавший фоновый цикл |
