# Настройки, включатели групп, ранги и «доступ команд»

## 1. Настройки чата (`настройки`)
- Значения по умолчанию: `db.py` → `DEFAULT_SETTINGS`.
- Экран: `handlers/settings.py` → `PAGES` (строки `("toggle", ключ, подпись)` и `("choice", ключ, подпись, [(текст, значение)])`).
- Чтение: `(await db.get_settings(chat_id))["ключ"]`; запись: `await db.set_setting(chat_id, "ключ", значение, actor_id)` (пишется в журнал).
- Полный список — `docs/SETTINGS.md` (генерируется). Рецепт — `templates/setting_template.md`.
- Тонкие команды-настройки текстом («капча время 45м», «норма 300») — `handlers/rulecmds.py`, `handlers/chatinfo.py`.

## 2. Включатели групп команд
`toggles.GROUPS` → ключи `*_on`. Админ выключает группу в «настройки → Команды»; роутер с `router.message.filter(Enabled("ключ"))`
молча игнорирует свои команды. Рецепт — `templates/toggle_group_template.py`.

## 3. Ранги
| Ранг | Кто |
|---|---|
| 0 | обычный участник |
| 1–2 | модераторы (выдаются `+модер 2 @ник`) |
| 3 | Telegram-админ с правом банить (автоматически) |
| 4 | старший модератор (максимальный выдаваемый, `MAX_ASSIGNABLE`) |
| 5 | создатель чата |

Эффективный ранг = max(выданный, по статусу Telegram): `mod_service.effective_rank`.

## 4. Доступ команд (ДК)
`ranks.DEFAULT_ACCESS` — какой минимальный ранг нужен каждой команде. Админ чата меняет командой «дк» (хранится в БД,
`db.get_access(chat_id)`). Использование: `need_rank(access, "бан")`.
Новая защищённая команда: добавьте её в `DEFAULT_ACCESS`, в хендлере сравните `effective_rank` с `need_rank(...)`.
Шаблон — `templates/admin_command_template.py`.

## 5. Владелец бота
`OWNER_ID` в `.env` (можно несколько). Панель владельца — `handlers/owner.py` (в личке): блок-лист, глобальные флаги
(`rt.flags`), режим обслуживания, рассылки, перезапуск. Глобальные флаги хранятся в `GLOBAL_DEFAULTS` (db.py).
