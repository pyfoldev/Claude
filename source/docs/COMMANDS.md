# Команды бота

Источник: `bot/handlers/menu.py` → `SECTION_DATA`.


## 🛡 Модерация

_Ответом на сообщение или с @ником. Причина: бан @ник 1д "спам"._

| Команда | Что делает |
|---|---|
| `бан` | забанить (бан 1д, бан навсегда) |
| `разбан` | снять бан |
| `кик` | исключить с возвратом |
| `мут 30м` | заглушить на срок |
| `размут` | снять мут |
| `варн` | предупреждение, 3 — автомут |
| `снять варн` | убрать предупреждение |
| `варны` | сколько предупреждений |
| `история @ник` | все наказания участника |
| `репутация @ник` | репутация и досье |
| `удалить` | удалить сообщение (ответом) |
| `закреп` | закрепить (ответом) |
| `открепить` | открепить |
| `чистка 20` | удалить последние сообщения |
| `жалоба` | пожаловаться (ответом) |
| `опрос Вопрос | да | нет` | создать опрос |
| `бан @ник 1д "причина"` | причина в кавычках или со следующей строки |
| `тбан / тмут / ткик` | тихо: без следа в чате |
| `дбан / дмут` | и удалить сообщение нарушителя |
| `вайп @ник` | удалить его сообщения за 48 ч |
| `амнистия` | снять все баны и муты |
| `+доверять @ник` | белый список: правила не трогают |
| `+триггер капс варн` | авто-наказание по событию |
| `триггеры` | список триггеров |
| `+блок стикер` | заблокировать набор (ответом) |
| `мут период 2ч` | срок по умолчанию (бан период, варны чс) |
| `модер лог` | кто и кому менял ранги |

## 📊 Статистика

| Команда | Что делает |
|---|---|
| `стата` | за сутки |
| `стата 2 часа` | за N часов (1–168) |
| `стата неделя` | за неделю |
| `стата месяц` | за месяц |
| `стата вся` | за всё время |
| `стата темы` | по темам форума |
| `моя норма` | сколько набрали за неделю |
| `кто не набрал` | отстающие от нормы (админам) |
| `норма 300` | норма сообщений в неделю (админам) |

## 🚫 Защита

_Включается в «настройки»._

| Команда | Что делает |
|---|---|
| `антиспам` | флуд, повторы, ссылки, пересылки |
| `антирейд` | массовый вход |
| `фильтр 18+` | картинки, стикеры, видео |
| `фишинг` | поддельные ссылки |
| `стоп-слова` | слова и выражения |
| `капча` | проверка новичков |
| `ИИ-модерация` | по желанию |
| `расшифровка` | голосовых |
| `удалять сообщения` | по типу: капс, стикеры, пересланные… |
| `фейс-контроль` | по профилю новичка |
| `быстрый выход` | бан за «вошёл-вышел» |
