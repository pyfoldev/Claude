# Порядок роутеров

Сверху вниз = приоритет: первый подошедший хендлер обрабатывает сообщение.
Источник: `bot/main.py` → `ROUTERS`.


### служебное: защита мафии, владелец, капча, веб-панель

| # | Модуль | Назначение |
|---|---|---|
| 1 | `mafia_handlers.guard` | Мафия: команды в группе, вход по ссылке в личку, кнопки ночи и голосования, предсмертные сообщения. Логика игры — bot/mafia.py. |
| 2 | `owner_handlers.router` | Панель владельца: управление ботом из личных сообщений. Доступна только пользователям из OWNER_ID. |
| 3 | `captcha.router` | Капча для новичков. |
| 4 | `webpanel_handlers.router` | Вход в веб-панель (Mini App): кнопки web_app работают только в личке, из группы ведёт кнопка-ссылка в личку бота. |
