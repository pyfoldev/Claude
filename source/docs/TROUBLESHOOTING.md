# Если что-то не работает

| Симптом | Причина / что делать |
|---|---|
| Бот не стартует: «BOT_TOKEN не задан» | заполните `.env` (см. `.env.example`) |
| «WEBHOOK_SECRET …» при старте | в режиме webhook нужен секрет 16–256 символов `A-Za-z0-9_-`, не «change-me-long-random» |
| Новая команда молчит | роутер не подключён → `python tools/check_project.py`; либо выше стоит хендлер, «съевший» сообщение (порядок в `ROUTERS`); либо нет прав/кулдаун (хендлер молча `return`) |
| `KeyError: 'мой_ключ'` | ключ настройки не в `DEFAULT_SETTINGS` (`db.py`) |
| Кнопка «крутится» бесконечно | не вызван `await cb.answer()` |
| «can't parse entities» | пользовательский текст/ответ ИИ без `html.escape` |
| Команда работает в личке, не в группе (или наоборот) | проверьте `message.chat.type` в хендлере |
| Бот не видит сообщения в группе | у бота включён privacy mode — отключите в @BotFather (`/setprivacy`) или сделайте админом |
| Не работает бан/мут | нет прав админа у бота (удаление, ограничение участников) |
| Капча не открывается | неверный `WEBAPP_URL`/Caddy; в группе Telegram не даёт web_app-кнопку — открывается через личку |
| ИИ молчит | нет `RIVER_API_KEY`, выключен `rt.flag("ai")` или настройка `ai_on` |
| Бот «залип» после падения | смотрите `docker compose logs bot`; владельцу приходит алерт; маркер `running.marker` показывает нештатное завершение |
| «database is locked» (SQLite) | не запускайте два процесса на один файл; для нагрузки — PostgreSQL |
| Перевод не применился | фрагмент не найден в `PHRASES` (подстрока должна совпадать точно) |
| Английская команда не распознаётся | нет записи в `ALIASES` или чат не в `en` |

Диагностика: команда владельца «диагностика» (`bot/diagnostics.py`), метрики — `metrics.py`, логи — `logging` (INFO по умолчанию).
